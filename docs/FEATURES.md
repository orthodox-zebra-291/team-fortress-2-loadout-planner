# Team Fortress 2 Loadout Planner — feature reference

The Team Fortress 2 loadout planner workflow separates class profiles from equipment notes and session records. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Class profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
